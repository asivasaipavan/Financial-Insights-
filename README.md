# Financial-Insights-

Financial Insights is a simple and interactive web application built to make finance easier to understand. It helps users calculate EMIs, analyze education loans, compare loan options across banks, understand insurance policies, and estimate gold loan eligibility.

## Features

- **EMI Calculator**  
  Calculate monthly EMI, total interest, and total payment for a loan.

- **Education Loan Calculator**  
  Estimate repayment after moratorium period and understand total repayment details.

- **Bank Suggestion System**  
  Suggests banks based on loan amount, affordable EMI, and collateral type.

- **Insurance Analysis Tool**  
  Compares sum assured, premium, coverage ratio, and cost of coverage.

- **Gold Loan Calculator**  
  Calculates gold value and eligible loan amount based on purity and RBI LTV rules.

- **Learning Center**  
  Includes educational content on EMIs, gold loans, insurance, education loans, investment basics, and saving strategies.

- **Responsive Design**  
  Fully responsive and mobile-friendly layout using Bootstrap.

- **Data Visualization**  
  Uses charts to show loan breakdowns and comparisons visually.
